# 🦆 Ducky Bot Dashboard

A modern Discord server management dashboard for Ducky SMP.

## ✨ Features

- 🏠 Dashboard
- 🛡️ Moderation
- 🤖 AutoMod
- 👋 Welcome & Goodbye
- 🎮 Leveling & XP
- 🎫 Tickets
- 🎁 Giveaways
- 🎭 Reaction & Button Roles
- 📢 Announcements
- 📊 Server Statistics
- ⚙️ Server Settings
- 🔐 Discord OAuth2 Login
- 📱 Mobile-friendly design
- 🧊 Liquid glass interface
